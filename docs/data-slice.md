## Running and verification

`npm run ingest` performs manual collection. `npm run ingest:watch` starts the independent daily local worker; `-- --interval-hours 1` enables hourly discovery. The machine and worker must remain running. Restart catches up; Ctrl+C stops it. There is no installed scheduler or service.

Every interval rediscovers public listings. Existing valid event facts are reused for 24 hours; corrections are then fetched from scratch within the rolling window. `--force` bypasses event caches. `--max-reads` bounds Limitless work per invocation, retaining discovery and completed-event progress for later retry. Rate-limit headers and Retry-After control pacing/cooldowns. A lease prevents overlapping publication; expiry recovers interrupted workers. Failure retries wait at least five minutes or a longer provider cooldown. Explicit archive retirement stops automatic collection.

Collection stages privately, validates record reconciliation, then atomically changes the active pointer. During failure, surviving cached facts remain usable; local date expiry is allowed to publish a smaller/empty cohort. Browsing reads a single cohort from an immutable publication ID. Local publication checks retain search, filters and detail state. Compressed durable cohorts decode on demand; legacy JSON publications remain readable. Raw snapshots, teams and quarantined evidence never enter browser props or the cohort endpoint.

Offline regressions cover statistical contracts, boundaries, aliases, source conflicts, pagination/checkpoints, retirement, worker scheduling, expiry, compression and rollback. Browser verification covers controls, keyboard focus, unavailable/empty states, failure retention, background publication replacement and narrow layouts. Source audits are separate. Local checks do not establish production readiness.

Validation passed: 36 offline tests, five focused browser tests, TypeScript, lint, production build and formatting. Desktop and 390px Tournament/Ladder previews had no browser exceptions or document overflow. Inspection uncovered a previously retained duplicate-species registration; both normalizers and cached-event reconciliation now invalidate the whole team, with original evidence retained. Build and usage denominators agree after republication.

Follow-up priorities: official RK9 team/result joins; a verified M-C rank/build ladder export; better administrative-result evidence; then pair-versus-pair tools. Artwork variants, other regulations, hosted operations and paid services remain separate scope.
